# AI 入门介绍

## 什么是人工智能

人工智能（Artificial Intelligence，简称 AI）是计算机科学的一个分支，旨在创建能够模拟人类智能行为的系统。AI 系统能够执行通常需要人类智能才能完成的任务，如视觉感知、语音识别、决策制定和语言翻译。

## AI 的主要分支

### 机器学习（Machine Learning）
机器学习是 AI 的核心子领域，通过算法从数据中学习模式和规律，而无需显式编程。常见算法包括决策树、支持向量机（SVM）、随机森林和梯度提升（XGBoost/LightGBM）。

### 深度学习（Deep Learning）
深度学习使用多层神经网络来学习数据的层次化表示。主要架构包括：
- **卷积神经网络（CNN）**：擅长图像识别和计算机视觉
- **循环神经网络（RNN/LSTM）**：用于序列数据，如文本和语音
- **Transformer**：当前主流架构，支撑 GPT、BERT、LLaMA 等大语言模型
- **扩散模型（Diffusion Models）**：图像生成领域的主力，如 Stable Diffusion、DALL-E

### 自然语言处理（NLP）
NLP 使计算机能够理解、解释和生成人类语言。典型应用包括：
- 文本分类与情感分析
- 命名实体识别（NER）
- 机器翻译
- 问答系统
- 文本摘要

### 计算机视觉（Computer Vision）
使计算机能够从图像和视频中提取有意义的信息。应用包括目标检测（YOLO、Faster R-CNN）、图像分割、人脸识别等。

## 大语言模型（LLM）

近年来，大语言模型的发展改变了 AI 领域的格局：
- **GPT 系列**（OpenAI）：从 GPT-3 到 GPT-4o，通用能力强
- **Claude 系列**（Anthropic）：注重安全性和长上下文
- **通义千问（Qwen）**（阿里云）：国产主力模型，qwen-plus 性价比高
- **DeepSeek**：开源模型中的佼佼者，推理能力强

## AI Agent 架构

AI Agent 是能够自主规划和执行任务的智能体系统：
- **ReAct 模式**（Reasoning + Acting）：交替进行推理和行动
- **Multi-Agent 协作**：多个专业 Agent 分工协作
- **Tool Use（函数调用）**：Agent 通过调用外部工具获取信息或执行操作

## AI 应用开发栈

Python 生态是 AI 开发的首选：
- **LangChain**：LLM 应用开发框架
- **LangGraph**：有状态的多步骤 Agent 工作流
- **LlamaIndex**：数据索引和检索增强生成（RAG）
- **HuggingFace**：模型仓库和推理库
- **vLLM / TGI**：高性能模型推理服务

## 向量数据库

向量数据库用于存储和检索高维向量嵌入，是 RAG 系统的关键组件：
- **ChromaDB**：轻量级开源向量数据库，适合中小规模应用
- **Pinecone**：全托管向量数据库服务
- **Milvus**：高性能分布式向量数据库
- **Weaviate**：支持混合检索的向量数据库

## RAG（检索增强生成）

RAG 将信息检索与文本生成结合，让 LLM 能够基于外部知识回答问题：
1. 用户提问
2. 查询重写（优化检索关键词）
3. 向量检索（从知识库中获取相关文档）
4. 重排序（按相关性排序）
5. 上下文拼接 + LLM 生成答案

RAG 的核心优势：
- 减少幻觉：基于真实文档回答
- 知识更新：不需要重新训练模型即可更新知识
- 可溯源：可以追溯到具体的来源文档
